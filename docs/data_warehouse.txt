TABLE GRAINS
- fact_delivery_task_gold: one completed delivery order per row.
- dim_courier_silver: one courier state per effective date (SCD2).
- eta_safe_gold: one candidate order at one query timestamp per row.
- eta_safe_metrics_gold: one metric result per run, split and seed.
- delivery_rejected: one rejected source order per row.

CURRENT DESIGN NOTE
- delivery_silver and delivery_bronze are staging layers, not star dimensions.
- region_id and aoi_id are degenerate dimensions stored in the fact today.
- A full star can add dim_region and dim_aoi later; this diagram intentionally
  reflects the tables that the current pipeline actually creates.
- delivery_minutes and target_remaining_minutes are labels, never features.
